# Chat UX design

Дата: 2026-08-18

## Цель

Сделать чат понятнее и ближе к паттернам `shotmate-monorepo/apps/web`: сразу виден общий чат, понятно как начать личный диалог, сообщения управляются через контекстное меню.

## Scope

- Добавить общий чат `Общий чат`, закрепленный первым пунктом списка.
- Если `/chat` открыт без выбранного диалога, показывать общий чат.
- Добавить явный старт личного диалога из чата: поиск/выбор друга открывает или создает direct thread.
- Добавить context menu по правому клику на сообщениях.
- Оставить текущие возможности: отправка текста, фото, ответ, редактирование, удаление, mobile layout и закрепленный composer.

## Data model

- Расширить `ChatThread` полями:
  - `kind`: `DIRECT` или `GLOBAL`, default `DIRECT`;
  - `title`: nullable, для общего чата `Общий чат`.
- Старые direct threads остаются совместимыми через `privateKey`.
- Для общего чата создавать `ChatParticipant` для пользователя при открытии `/chat`, чтобы работали unread counters и `lastReadAt`.

## Server flow

- `getChatPageData` гарантирует наличие общего чата и возвращает его первым в `threads`.
- Если `threadId` и `userId` не переданы, активным становится общий чат.
- Для direct threads остается проверка дружбы.
- Для global thread читать и писать могут авторизованные пользователи.
- Уведомления о сообщениях остаются для direct threads. Для общего чата не создаются персональные уведомления всем участникам.

## UI flow

- Список чатов:
  - сверху `Общий чат` с отдельной иконкой;
  - ниже блок старта личного диалога с поиском по друзьям;
  - существующие диалоги остаются ниже.
- Header активного чата показывает название общего чата или имя собеседника.
- Сообщение само становится trigger для context menu, как в `shotmate`.
- Меню сообщения:
  - `Ответить`;
  - `Копировать`, если есть текст;
  - `Редактировать`, если сообщение свое или пользователь admin;
  - `Удалить`, если сообщение свое или пользователь admin.
- Видимые quick action buttons можно оставить как fallback для мобильного и hover.

## Verification

- Добавить/обновить тесты серверной логики чата, если текущий test setup позволяет проверить server helpers без лишней инфраструктуры.
- Минимально проверить:
  - общий чат создается и возвращается первым;
  - `/chat` без параметров открывает общий чат;
  - direct thread по-прежнему требует дружбу;
  - context menu содержит действия с учетом прав.
- Запустить `pnpm test`, `pnpm typecheck`, `pnpm build`.
