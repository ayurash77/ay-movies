# Индивидуальные превью трейлеров

## Проблема

Все карточки трейлеров используют постер фильма, хотя ролики различаются. API
Kinopoisk Unofficial возвращает название, URL и источник видео, но не возвращает
превью отдельным полем. У Kinopoisk Widget индивидуальное изображение находится
в данных страницы плеера.

## Рассмотренные варианты

1. Показывать iframe каждого плеера прямо в галерее. Это даёт настоящее превью,
   но создаёт несколько тяжёлых cross-origin iframe и ухудшает загрузку страницы.
2. Загружать превью при каждом открытии страницы фильма. Это не требует хранения,
   но делает интерфейс зависимым от Kinopoisk и повторяет сетевые запросы.
3. Получать превью один раз во время импорта метаданных и хранить рядом с видео.
   Это выбранный вариант: страница фильма остаётся быстрой и читает локальный
   snapshot.

## Данные и импорт

- В `MovieVideo` добавляется nullable `thumbnailUrl`.
- `MovieVideoMetadata` получает optional nullable `thumbnailUrl` с проверкой
  безопасного HTTPS URL и ограничением длины.
- Для YouTube превью вычисляется детерминированно по video ID.
- Для Kinopoisk Widget сервер загружает страницу выбранного плеера, извлекает
  изображение именно для его trailer ID и нормализует protocol-relative URL в
  HTTPS.
- Получение превью ограничивается timeout и bounded concurrency. Ошибка одного
  плеера не отменяет импорт остальных видео и данных фильма.
- Пустой результат обновления не стирает уже сохранённое превью.

## UI

- Карточка сначала использует `video.thumbnailUrl`.
- Постер фильма больше не используется как превью трейлера.
- Если индивидуального изображения нет или оно не загрузилось, показывается
  стабильная нейтральная видеоплашка с иконкой и кнопкой воспроизведения.
- Iframe по-прежнему создаётся только после клика по карточке.

## Обновление старых данных

Миграция только добавляет nullable-колонку и не выполняет сетевой backfill.
Старые фильмы получают индивидуальные превью после обычного действия
`Обновить` на странице редактирования. До обновления используется нейтральная
плашка.

## Проверки

- Unit-тесты извлечения Kinopoisk Widget preview и YouTube thumbnail.
- Проверка схемы и сохранения `thumbnailUrl` в video snapshot.
- UI-тест: разные видео используют разные изображения, а отсутствие превью не
  возвращает постер фильма.
- Полные `pnpm test`, `pnpm typecheck` и `pnpm build`.
